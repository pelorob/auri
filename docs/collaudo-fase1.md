# Collaudo fase 1 (iPad)

Installare `dist/v0.1.2/auri.ipa` con SideStore (vedi docs/guide/installazione-ipad.md).

- [ ] Primo avvio: 3 passi, poi la Home
- [ ] Creare 3 corsi (uno a idoneità), registrare 2 voti (uno 30 e lode): media e base corrette
- [ ] Libretto: simulatore "E se…" e obiettivo 100/105/110 rispondono
- [ ] Creare un appello tra 2 giorni con preavviso "1 giorno prima": la notifica arriva domani alle 9:00
- [ ] Iscritta / Non iscritta cambia con un tocco
- [ ] Eliminare un corso con appello: sparisce anche dal calendario
- [ ] Ruotare l'iPad: in verticale compare la barra in basso
- [ ] Attivare Touch ID, chiudere l'app 6 minuti: al ritorno chiede lo sblocco. Provare "Usa il codice dell'iPad"
- [ ] Esporta backup → salvare su iCloud Drive. Cancellare un corso. Ripristina backup → il corso torna
- [ ] Ripristinare una foto come backup: messaggio d'errore, dati intatti
- [ ] Impostazioni mostra "Firma valida fino a: …"; con ≤ 3 giorni la Home mostra l'avviso
